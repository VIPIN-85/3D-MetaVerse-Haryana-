# Haryana 3D Metaverse 🌐

**An Interactive 3D Digital Twin of Haryana, India**

Explore a futuristic 3D visualization of Haryana that brings together urban development, cultural heritage, industrial infrastructure, agriculture, and transportation in an immersive digital environment.

## 🚀 Features

- **Interactive 3D Environment:** Explore a procedurally generated landscape powered by Three.js.
- **Gurugram Cyber City:** Discover futuristic skyscrapers, commercial districts, and elevated metro infrastructure.
- **Kurukshetra Heritage:** Explore a digital representation inspired by Brahma Sarovar, historic monuments, and cultural landmarks.
- **Faridabad Industrial Zone:** Visualize industrial facilities, manufacturing areas, and energy infrastructure.
- **Agricultural Green Belt:** Experience digital representations of farmland, irrigation systems, grain storage, and renewable energy.
- **Transportation Infrastructure:** Explore highways, bridges, and metro corridors.
- **Dynamic Lighting:** Switch between daytime, golden-hour, and nighttime environments.
- **Interactive District Navigation:** Select different regions and focus on their landmarks.
- **Simulation Layers:** Toggle available transportation, weather, and GIS grid visualizations.
- **Camera Controls:** Orbit, pan, zoom, and explore the 3D scene.

## 💻 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if you do not already have it.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.

An internet connection is required to load the external libraries and fonts.

## 🌍 Deployment

This project can be hosted using GitHub Pages.

1. Upload `index.html` to the root of your repository.
2. Open **Settings → Pages**.
3. Select the `main` branch and the root folder.
4. Save and wait for deployment.
5. Open the published website URL provided by GitHub Pages.

## 🎯 Project Vision

The goal is to create an interactive digital visualization of Haryana that combines urban innovation, cultural identity, industrial development, agricultural landscapes, and transportation infrastructure in one immersive 3D experience.

## ⚠️ Disclaimer

This project is a conceptual 3D visualization. Some structures, infrastructure layouts, metrics, and simulation values are illustrative and should not be interpreted as verified real-time data or an authoritative geographic digital twin.
